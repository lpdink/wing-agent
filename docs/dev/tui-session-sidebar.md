# TUI 会话侧边栏

在长时间打开的 `wing` TUI 中，用户需要随时看到其他会话是否在运行、是否在等回答，以及它们属于哪个工作区。侧栏把这些信息留在聊天旁边，点击条目即可切换。侧栏沿用 `/ss` 的状态字形、主题色和会话排序规则。

## 界面与操作

```text
 Wing · model                                          session-id
┌─ 会话 · F2 ──────────────────┬─────────────────────────────────┐
│ ▾ ● 发布准备             ★  │                                 │
│     wing-agent · 14:26       │  聊天                           │
│     ? 等待确认发布版本       │                                 │
│       wing-agent · 14:24     │                                 │
│ ▸ ● 修复文档链接             │                                 │
│     wing-app · 14:05         │  输入                           │
└──────────────────────────────┴─────────────────────────────────┘
```

- **会话行**占两行。第一行显示状态、标题和置顶标记，第二行显示工作区末段与该会话最近活动时间。工作区缺失时显示会话 ID，标题缺失时使用 `/ss` 的无标题文案。运行中用主题警示色，等待回答用 `?`，空闲和未加载沿用 `/ss` 的常规色与弱化色。当前会话整行高亮，使用明暗主题的选中样式。宽度不足时按终端显示列截断标题和路径。
- **会话树**沿用 Rust `Forest` 的 pin、等待优先、最近活动和父子顺序。子树初次显示时展开，点击 `▸` 或 `▾` 折叠或展开。折叠时显示后代总数、等待数与运行数，帮助用户定位需要查看的分支。切换会话后展开目标的祖先并把目标滚入视口。
- **点击与滚轮**由侧栏所在列处理。单击条目的任一行切换会话，单击当前会话保持原位。滚轮在侧栏内滚动会话，移到聊天区继续滚动聊天。切换允许离开正在运行或等待回答的会话，回到等待中的会话时由现有历史快照恢复提问。草稿及附件沿用当前 TUI 的跨会话草稿语义。设置浮层拥有背景指针，连接断开或正在等待会话快照时暂缓接受新的切换点击。
- **F2**切换本次 TUI 的展开意愿，终端上报重复按键时忽略重复事件。侧栏标题及开屏提示可发现该键。沿用应用保留键的优先级，设置浮层打开时交由设置面板处理。无鼠标时仍可通过 `/ss` 搜索和切换。
- **布局**在状态栏下方分栏，聊天、输入卡、命令弹出列表和提示使用主栏宽度。侧栏宽度为终端宽度的 28%，限制在 30 到 40 列。终端少于 100 列或 8 行时暂时收起，恢复尺寸时按用户的展开意愿显示。窄窗口下按 F2 尝试展开时，提示所需尺寸。

会话行集跟随网关的未归档列表。当前会话未出现在列表时，TUI 用本地会话身份补出该行，等网关提供正式条目后按 ID 接替。可用 `/ss` 搜索会话。

## 配置接口

以下为 `$WING_HOME/tui/config.yaml` 的默认值。未设置 `WING_HOME` 时路径为 `~/.wing/tui/config.yaml`。

```yaml
layout:
  session_sidebar:
    default_open: false
    side: left
```

`side` 接受 `left` 或 `right`。两个字段通过现有 Interface 配置目录校验、显示与保存，`wing tui --dump-config` 走同一目录。`side` 在 `/settings` 内即时预览并支持取消回退。`default_open` 决定下一次启动的初始状态。F2 只改变当前进程的显示状态。

## 数据与接入

- **列表与切换**走现有 `GET /api/session/list` 和 TUI 的 `ResumeSession` 流程。当前会话高亮随已有快照提交点更新。目标在点击前已被归档、或恢复请求失败时，沿用已有错误提示。目标打开后由现有订阅回放聊天、未提交内容和待回答的提问。
- **刷新**在首次可见、重新展开、重连或本端影响列表的操作完成后请求。可见期间，列表有运行中或等待中的会话时每 8 秒刷新，否则每 30 秒刷新。列表接口在状态筛选前仍会扫描同一个会话集合，侧栏取完整快照，以便发现外部新建、改名及归档。请求在后台运行，同一时间最多一个列表请求，期间到来的刷新需求合并。收起、过窄或断线时暂停侧栏轮询，`/ss` 仍可主动请求列表。拉取失败时保留最近一次成功列表并显示更新失败状态。连续失败时逐次延长轮询间隔，最长 60 秒，成功后恢复正常节奏。
- **共享**会话摘要的事实投影、`Forest` 排序、状态字形与主题色。侧栏持有自己的展开与滚动状态，`/ss` 持有搜索词、层路径与键盘光标。侧栏定时刷新不移动 `/ss` 光标，`/ss` 主动刷新可以复用在途列表请求。当前会话的本地状态可由 TUI 已收到的事件即时更新，后台会话以列表快照为准。
- **帧与鼠标**先确定左右分栏，再使用主栏宽度计算聊天换行、开屏、输入区和选择锚点。侧栏渲染记录本帧可见条目的矩形、会话 ID 和折叠热区。鼠标按下与松开须命中同一会话 ID 和同一操作才提交，刷新重排、调整宽度或关闭侧栏时避免误点。刷新按首个可见会话 ID 恢复滚动位置。

## 验收

| 场景 | 预期 |
| --- | --- |
| 旧配置、新配置、F2 | 旧配置启动时隐藏。`default_open: true` 分别在左、右两侧生效。F2 连续开关不写文件，重启按配置恢复。 |
| 窗口宽度换档 | 窄屏使用全宽聊天。放宽后按展开意愿恢复。两种方向的输入换行、弹出列表、选区和聊天滚动命中正确。 |
| 多会话运行 | 展开时可看到当前高亮和后台会话的空闲、运行、等待状态。折叠后可从计数定位后台等待。外部增删会话在下次成功刷新后反映到列表。 |
| 点击切换 | 两行均可点。折叠控件只切换子树。切换到未加载、运行中和等待中的会话后显示各自的快照。刷新重排或拖动期间不误切。 |
| 断线和慢请求 | 拉取期间可继续输入与滚动。失败保留旧列表并标明状态，重连后补刷。侧栏隐藏时无定时请求。 |
| 回归 | `/ss` 的搜索、层视图和键盘切换纳入分栏、鼠标命中、配置往返和列表请求的回归测试。 |

相关约定见 [会话血缘与 `/ss`](session-lineage.md)、[TUI 输入通道](tui-input.md)、[TUI 配置](config-logging.md)。
